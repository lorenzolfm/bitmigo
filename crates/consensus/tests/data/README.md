## Generated by bitcoind (`regtest-headers.json`)

Fifteen regtest headers, genesis included, with Core's own `mediantime`, `bits` and
`chainwork` for each, read by the `header` module's tests as the oracle for median time past,
block work and the two header stages. Mined by `bitcoind -regtest` v31.1.0 with the block
times forced through `setmocktime`, so that the timestamps go backwards in places and the
median is not just the middle block:

```
G=1296688602   # regtest genesis time
for off in 1000 200 3000 2500 400 5000 4800 4900 7000 6000 8000 100 9000 9500; do
  bitcoin-cli -regtest setmocktime $((G+off))
  bitcoin-cli -regtest generatetoaddress 1 <any regtest address>
done
# then, per height: getblockhash, getblockheader <hash> true (the fields),
# getblockheader <hash> false (the raw header)
```

Each record: `height`, `hash`, `header` (the 80 raw bytes, hex), `time`, `mediantime`,
`bits`, `chainwork`, `version`, as `getblockheader` reports them. The generated data is not
copyrightable in any meaningful sense; it is published under this repository's licence.
